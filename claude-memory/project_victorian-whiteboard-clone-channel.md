Decisions made 2026-09-18:
- Niche angle: period/geography-specific (like Eternal Rome/Historidame), not prehistoric (avoids direct overlap with Ink Explainer/Axen)
- Chosen period: **Victorian** — despite [[victorian-sleep-hybrid-production]] already covering Victorian content, this is a DIFFERENT concept: fast-paced whiteboard-doodle explainer (8-12min, hook-driven, Ink Explainer script formula) vs the sleep-story channel's slow hybrid AI+stock sleep-tempo format. ## Video 2 sync bug — found and fixed (2026-09-21)
User reported the delivered video 2 had visual/audio desync: images and clips appeared BEFORE the VO reached the matching content, and the offset grew worse deeper into the video.

**Root cause**: the edit sheet's `dur` column was each Whisper segment's own span (`end - start`). Whisper segments have small gaps between them (pauses/breaths — e.g. 6.4s→7.6s, a 1.2s gap). Those gaps were never assigned to any clip, so when the render script concatenated all 43 clips back-to-back with zero gap, the video's cumulative timeline ran shorter than the VO's real timeline at every single gap. The error is small per-gap but accumulates monotonically — by minute 6 the visual was noticeably running ahead of the audio. The original fix for the video's total length (a single `tpad` clone at the very end to reach 392.4s) papered over the aggregate shortfall but did nothing for the internal frame-by-frame drift, which is what the user actually noticed.

**Correct fix**: recompute each clip's on-screen duration as `next_clip_start - this_clip_start` (the last clip = `VO_total - its_own_start`), so each image holds the screen exactly until the next one is due to appear, silence gaps included. This makes the concatenated timeline match the VO's absolute timeline by construction — no synthetic end-padding needed, and zero cumulative drift. Two of the 22 animated (Veo, fixed-8s-source) clips ended up needing slightly more than 8s under the corrected numbers (8.1s, 8.3s) — handled by trimming to the 8s source and freeze-extending the last frame with `tpad` for the small remainder, same technique as the hard-loop-extension precedent in [[victorian-sleep-hybrid-production]].

**Standing rule for all future videos on this channel**: build the edit sheet's clip durations from consecutive Whisper segment START times (`next_start - this_start`), never from each segment's own `(end - start)` span. The `(end-start)` approach looks correct in isolation but silently drops inter-segment gaps and causes exactly this kind of progressive desync. Video 1 (`victorian_ink_video1_edit_sheet_FINAL.md`) was built the same (buggy) way and was NOT rechecked — if video 1 gets revisited, apply the same fix.
